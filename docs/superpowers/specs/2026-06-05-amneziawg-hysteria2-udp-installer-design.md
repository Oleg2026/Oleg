# Спецификация: `autoXRAY-udp.sh` — установщик AmneziaWG + Hysteria2

**Дата:** 2026-06-05
**Статус:** утверждён дизайн, ожидает плана реализации
**Контекст:** мобильный ТСПУ РФ научился поведенчески/репутационно блокировать TCP-REALITY/XHTTP
(паттерн: случайные обрывы, восстановление от минуты до часа). UDP-класс протоколов
(AmneziaWG, Hysteria2) не подпадает под «заморозку 16 КБ в TCP» и большинство TCP-эвристик,
поэтому добавляется как параллельный путь на **отдельном VPS**.

Источники механики блокировки: net4people/bbs#490 (заморозка соединения после ~25 пакетов /
~16 КБ к иностранному IP по TLS), наблюдения по мобильным операторам РФ 2026.

---

## 1. Назначение и интерфейс

Новый, **третий** скрипт проекта. Существующие `autoXRAY1.sh` и
`autoXRAYselfRUbrEUxhttp.sh` не изменяются.

Ставит на чистый Debian 12 (root) два UDP-протокола против мобильного DPI —
**AmneziaWG** и **Hysteria2** — и отдаёт HTML-страницу подписки с QR и кнопками «Add to Happ»
в стиле autoXRAY.

```bash
bash -c "$(curl -L .../autoXRAY-udp.sh)" -- поддомен3.вашДОМЕН.com
```

- Аргумент `$1` — **домен** (обязателен). Нужен Hysteria2 для настоящего TLS-сертификата
  Let's Encrypt и для selfsteal-страницы.
- Проверки на старте (паттерны из autoXRAY): root (`$EUID`), непустой домен,
  совпадение `hostname -I` с A-записью (`dig +short`), запрос на продолжение при несовпадении.

## 2. Архитектура и распределение портов

| Компонент | Порт | Роль |
|---|---|---|
| nginx + certbot (selfsteal) | TCP 443 | сайт-маскировка + хостинг страницы подписки; выпуск серта Let's Encrypt |
| Hysteria2 | UDP, listen `443`; хоппинг-диапазон `20000–40000` → DNAT на listen | QUIC + Salamander-обфускация + port-hopping; берёт общий серт certbot |
| AmneziaWG | UDP `51820` | обфусцированный WireGuard со своим набором junk-параметров |

- TCP 443 (nginx) и UDP (Hysteria2/AWG) не конфликтуют.
- Пробер на TCP 443 видит реальный сайт-маскировку (selfsteal сохраняется).
- Hysteria2 **не** поднимает свой ACME — читает сертификат из файлов certbot, чтобы не
  конкурировать за порт 80/443.

## 3. Генерируемые при каждом запуске секреты (философия autoXRAY — всё свежее)

- **AmneziaWG:** пара ключей сервера и клиента; `Address`/`AllowedIPs`; обфускация
  `Jc, Jmin, Jmax, S1, S2, H1, H2, H3, H4` в валидных диапазонах. Параметры обфускации
  **обязаны совпадать** на сервере и клиенте.
  - Диапазоны: `Jc` 3–10; `Jmin < Jmax`, оба в пределах ~50–1000; `S1, S2` < ~1280 и `S1 != S2`;
    `H1..H4` — различные случайные 32-битные значения > 4.
- **Hysteria2:** пароль аутентификации, пароль обфускации Salamander, диапазон порт-хоппинга.
- **NAT:** включить `net.ipv4.ip_forward=1` + `MASQUERADE` (nftables/iptables) на внешний интерфейс,
  чтобы клиентам шёл интернет.

## 4. Установка протоколов

- **Системная подготовка** (из autoXRAY): `apt-get update`; пакеты
  `curl jq dnsutils openssl nginx certbot qrencode iptables`; включение BBR
  (`/etc/sysctl.d/999-autoXRAY.conf`); лимиты `nofile` 65535.
- **Сертификат:** блок certbot из autoXRAY1.sh, **но с исправленным порядком** — сначала
  `certbot certonly --webroot`, и только после успеха `cp` сертификатов в рабочий каталог
  (в autoXRAY1.sh копирование стоит до выпуска — баг, здесь не повторяем).
- **Hysteria2:** официальный бинарь, **версия запиннена** (не `latest`); systemd-юнит;
  конфиг `/etc/hysteria/config.yaml` (listen UDP 443, tls→файлы certbot, auth password,
  obfs salamander, при желании masquerade→nginx selfsteal).
- **AmneziaWG:** модуль ядра через **DKMS** из репозитория AmneziaWG;
  **фолбэк на userspace `amneziawg-go`**, если модуль не собрался под ядро VPS;
  `awg-quick up awg0` + systemd-enable; конфиг `/etc/amnezia/amneziawg/awg0.conf`.
- **Port-hopping:** правило DNAT (UDP-диапазон `20000–40000` → listen-порт Hysteria2),
  сохранение через `netfilter-persistent`.

## 5. Вывод для клиента

Переиспользуется HTML-генератор из autoXRAY (тёмная тема, Copy, QR-модалка, Add to Happ).
Страница `/<rand>.html` в `/var/www/$DOMAIN`, отдаётся nginx по HTTPS. Содержимое:

- **Hysteria2:** ссылка `hysteria2://<password>@<domain>:<range>/?obfs=salamander&obfs-password=...&sni=<domain>#...`
  — QR + deep-link в Happ.
- **AmneziaWG:** конфиг `.conf` для импорта — QR конфига (скан в Happ) + кнопка скачивания.
- Подвал/ссылки как в autoXRAY.

**Оговорка о формате подписки:** AmneziaWG и Hysteria2 — не Xray-конфиги, поэтому в единый
JSON-сабскрайб autoXRAY они не помещаются. Отдаём их **отдельной HTML-страницей** (ссылки + QR),
а не как xray-подписку. Happ принимает оба формата по ссылке/QR.

## 6. Обработка ошибок и финальные проверки

- root / домен / A-запись — как в autoXRAY (с запросом подтверждения при несовпадении IP).
- Проверка кода возврата certbot; при ошибке — понятный блок и `exit 1`.
- Предупреждение: **доступность UDP снаружи скрипт гарантировать не может**. В конце —
  команда самопроверки и подсказка «если UDP режется — расширьте диапазон порт-хоппинга».
- Финальный блок статусов: `nginx`, `hysteria-server`, `awg-quick@awg0` →
  RUNNING/ERROR (формат `=== Финальная проверка ===` из autoXRAY).

## 7. Идемпотентность и совместимость

- Повторный запуск перегенерирует ключи (как в autoXRAY).
- Клиент: Happ (Windows/Android/iOS/macOS/Linux) — поддерживает оба протокола.

## 8. Утверждённые решения

1. Домен **обязателен** (настоящий серт Hysteria2 + selfsteal).
2. Порты: AmneziaWG `udp/51820`; Hysteria2 listen `udp/443`; хоппинг `udp/20000–40000`.
3. AmneziaWG: DKMS-модуль с фолбэком на `amneziawg-go`.
4. Имя скрипта: `autoXRAY-udp.sh`.
5. Hysteria2: версия **запиннена**, не latest.

## 9. Открытые технические риски (учесть при реализации)

- **DKMS-сборка AmneziaWG** под ядро конкретного VPS — самый хрупкий шаг; обязателен фолбэк
  на `amneziawg-go` и понятное сообщение при провале обоих путей.
- **UDP/QUIC троттлинг** у части операторов — снимается port-hopping'ом, но не на 100%;
  это ожидаемое ограничение, фиксируем в выводе скрипта.
- **Пиннинг версий** Hysteria2 и AmneziaWG — нужно периодически обновлять вручную
  (компромисс ради стабильности против «latest ломает конфиг»).
